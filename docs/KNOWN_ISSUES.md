# 已知問題

## 尚待實機回歸

只建立框、索引與連線，沒有把框內內容另行複製或放大。動態參數接受寬／高、WID／HEI、距離1／2、DIST1／2 或 PARAM 類名稱；需逐一驗證原圖塊。

## 使用限制

只建立框、索引與連線，沒有把框內內容另行複製或放大。動態參數接受寬／高、WID／HEI、距離1／2、DIST1／2 或 PARAM 類名稱；需逐一驗證原圖塊。

需要 `FRAME` 動態圖塊與 `blowup tag` 圖塊，存在目前圖檔或可由支援路徑找到同名 DWG。輸出固定為 PaperSpace。

本次保留原始碼位元組，未修補功能；上述來源觀察不等於 AutoCAD 實機驗證結果。[返回 README](../README.md)。
